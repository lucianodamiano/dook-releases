# Dook

Signed and notarized builds of **Dook**, a Dock for macOS 26.

**Download:** [dook.lucianodamiano.it](https://dook.lucianodamiano.it)

This repository holds only Dook's releases: the app as a disk image, its updates and their release notes. The source code is not published. Dook checks for updates by itself and installs them from inside the app.

Questions and feedback: [dook.lucianodamiano.it/en/contact](https://dook.lucianodamiano.it/en/contact/).
